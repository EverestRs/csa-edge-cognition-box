## 0. 一句话定位与价值宣言

**作品定位**：慧眼智警·边缘认知盒——单颗国产昇腾 NPU（8 TOPS、≤20W、全本地）上的**可对话、可布控、可自述思维**的视觉安全 AIoT 系统：确定性感知层守住毫秒级判定，微型语言层负责"听懂人话、说出人话"，整条认知链路在演示屏上实时可见。

**价值宣言（评委视角的三句话）**：
1. 我们不做"把大模型硬塞进开发板"——我们做的是**边缘分层认知架构**：语言模型只做语言，确定性小模型守住视觉；
2. 我们不做"跑分自证的算法 demo"——我们把**AI 的决策过程做成演出**：三级决策、复核翻案、置信度流转，全部实时字幕化，评委看得见边缘 AI 的"思考"；
3. 单盒、无云、全国产、隐私不出域——**资源受限不是妥协，是设计**。

**诚实交底**：本版主动收缩嵌入式硬件（执行机构/传感网络/外壳工程），完整性 10% 的"实物外壳/PCB"得分项受损，技术性 35% 的"软硬件设计复杂度"半边让位——这是"算法主体"价值排序下的交换，边缘部署优化半边（内存/速度/功耗）仍全量保住（EDGE §9）。

## 1. 系统架构（最小合规壳）

```
网络/USB 摄像头(图像传感器,数据采集) → RTSP/USB →
┌── Atlas 200I DK A2 边缘认知盒（昇腾310B · 单盒 · ≤20W · 无云）──┐
│ L1 确定性感知：RTSP 取流 → YOLOv8n OM@NPU → ByteTrack →          │
│               ViTPose133 → PoseClassifier → Crop多分类器 → 规则   │
│ L2 分层决策：置信度三级分流(高采纳/灰区crop仲裁/低兜底)+时序平滑 │
│ L3 语言交互：Qwen2.5-0.5B(纯文本,盒上定案)——一句话布控解析·      │
│              感知事实→旁白合成·场景记忆问答                      │
│ L4 可解释呈现：复核链路字幕流·点谁说谁·底牌角标(fps/内存/功耗)   │
│ FastAPI+WebSocket ｜ Mosquitto(MQTT) ｜ Streamlit 看板           │
└─────────────────────────────────────────────────────────────────┘
        MQTT(网络通信) → 笔记本/手机浏览器看板(IoT应用,端云联动)
```

**AIoT 三能力合规映射**：数据采集 = 摄像头图像传感器（H.264 RTSP 全链路：采集-传输-硬解-推理）；网络通信 = MQTT（遥测/事件上行、规则下行、LWT 在线）；边缘 AI 推理 = 单盒四层。**轻壳，但合法。**

## 2. 五个演示时刻（方案的组织核心）

> 每个时刻 = 一个可排练、可剪辑、可答辩的单元。里程碑围绕它们排布，视频脚本就是它们的串联。

### 时刻① 一句话布控（旗舰，创新叙事主轴）
- **触发**：看板输入框现场敲入"识别有人在实验室门口逗留超过 2 分钟""找出鼓掌的人"；
- **屏上效果**：≤10s（盒上 0.5B 实测 p50 3.9–8.6s，2026-11-05 定案口径；开发机 7B 约 2s）规则解析卡片出现（闭集映射/开放描述/阈值）→ 热部署 → 志愿者行为发生后 ≤5s 告警卡弹出、时间轴打标、视频跳转证据帧；
- **底座**：文本 LLM 解析（v2.x 里这是 7B VLM 的活）+ 现有三级决策 + crop 多分类器演示类兜底 + `rule/set` MQTT 下行；
- **创新点**：自然语言→布控规则的编译链，"改布控像发微信"；执行反馈在 UI（告警卡/跳转/标记）——**纯软件系统的"执行"本来就在屏上**；
- **验收**：盒上口径解析 ≤10s（0.5B）+ demo_pack 预置口令二选一输入兜底；部署即生效（无重启）；同规则墙钟冷却防刷屏（现成）；
- **备用剧本**：LLM 解析慢→预置三条规则现场二选一输入（仍是真实解析路径）。

### 时刻② 点谁说谁（语言层能力秀，"AI 旁白"）
- **触发**：演示视频上鼠标点一个跟踪目标；
- **屏上效果**：≤1s 旁白字幕流出现："该人员近 90 秒三次接近围栏，当前判定徘徊（0.61），crop 复核维持，置信度爬升至 0.83"；
- **底座**：**感知事实编译器**（检测属性/轨迹统计/行为标签/crop 判定/时间线 → 结构化事实 → 文本 LLM 合成）——注意：**不走图像→VLM**，旁白是对传感器事实的语言化，绕开小模型视觉悬崖，效果反而更稳；
- **创新点**：边缘"多模态融合"的务实实现——视觉确定性结构化 + 语言生成，赛题点名方向（多模态融合）的正解；
- **验收**：旁白与事实一致（不产生画面外幻觉）；首响 ≤1s（缓存/异步兜底），实时生成 p50 4–6s（0.5B 实测）；
- **备用剧本**：预生成三条典型旁白，现场点击优先走实时、超时切缓存。

### 时刻③ 和录像聊天（场景记忆，检索问答）
- **触发**："刚才 5 分钟门口发生了什么？有人吸烟吗？"；
- **屏上效果**：≤10s 文字回答 + 证据截图卡跳转（SceneNarrator 叙述段 + 事件记忆）；
- **底座**：现有 SceneIndex（BM25+bge）+ 叙述日志 + 文本 LLM 合成回答（新增问答入口，薄层）；
- **创新点**：边缘侧"视频可对话"——不是云端回查，是全盒内自治的短期记忆；
- **验收**：演示时段内提问必命中（叙述间隔 20s 现成，问答窗口 ±5min）；
- **备用剧本**：问答检索为空→降级为"叙述时间线"直接展示（真实存在的数据）。

### 时刻④ 让 AI 说出自己的思考（fancy 浓度最高，全场独一份）
- **触发**：贯穿①②③的常开字幕带（"认知过程视图"开关）；
- **屏上效果**：每次灰区判定，屏幕实时展开推理链小卡：`主路径: 徘徊 0.61 → 落入灰区 → crop复核: 吸烟=否/徘徊=是 → 翻案: 维持徘徊↑0.83 → 布控规则命中 → 告警`——**评委第一次看见边缘 AI 的认知过程**；
- **底座**：三级决策阈值分流 + crop 仲裁 + 否决/采纳逻辑（全部已实现，缺的只是**呈现**）——工程量 2–3 天，全是前端+日志字段；
- **创新点**：可解释边缘智能。答辩话术："大多数端侧作品只给结论，我们把不确定性处理过程做成可观测对象——这是分层认知架构的直接证据，不是装饰"；
- **验收**：字幕带延迟 ≤1s、与实际决策一致（从 FrameResult 字段直出，不编造）；
- **备用剧本**：常开改为事件触发展开，降低屏上噪声。

### 时刻⑤ 底牌数据（技术性 35% 的常驻证据）
- **形态**：看板四角常驻角标：处理帧率、内存占用、NPU 占用、**板级功耗（npu-smi 直出，无需 INA226）**，外加徽章"单盒·本地·无云·国产芯片"；
- **用途**：每个时刻都让镜头扫到角标——"边演示边证技术"；
- **验收**：数据真实刷新（遥测 topic 周期约 1–5s，随 npu-smi 采集负载浮动）。

## 3. 算法创新叙事（创新性 25%，四支柱）

1. **零标注冷启动（VLM-as-Teacher 蒸馏）**：中心侧大教师（Qwen2.5-VL）生成 23,637 伪标签 → 蒸馏至毫秒级边缘模型；本作品把它讲成边缘方法论——"教师不在现场也能学会校园行为"；数据背书：主路径 85.7%、+19.1pp；教师同源偏差如实披露（评审加分的诚实项）；
2. **语言只做语言、视觉保持确定性（v3.0 架构主张）**：微型文本 LLM + crop 确定性仲裁的分层认知架构，正面回应"小模型视觉不可靠"（我们的审计：7B 对 <150px 目标已 50/50）——**这是从失败数据里长出来的架构，不是拍脑袋**；
3. **一句话布控**：自然语言→边缘规则的编译链（闭集映射 + 开放描述 + 演示类扩展），赛题"人机协同应用"的满分注脚；
4. **可解释复核链可视化**：边缘 AI 决策过程实时可观测——同赛道作品里几乎没有的呈现层。

（注：当前盒为 4GB，VL-2B 交替档 stretch 无内存资格，**不启用**；开放词汇以 crop 演示类 + 预置口径覆盖。8GB 盒到位时才评估第五支柱。）

## 8. 风险登记（含评委问答）
